Main Console
Authorized testing only. Only deploy and scan agents, models, or endpoints you own or are explicitly authorized to test. Configure only credentials that are approved for security testing.

1. Import Agent

Import real source code. No mock/demo projects are created by this interface.

Click the field above to open your file explorer and pick a local AI-agent source folder. The browser packages it and uploads it into managed Agent Lab storage under ./agent-lab/projects/; VulnoraIQ never receives a raw local filesystem path.

Desktop Mode creates ./projects/ beside the launcher. Place a real AI agent in ./projects/<agent-name>/, then refresh. Managed imports live in ./agent-lab/projects/.

Mapped projects are read-only. If a mapped project has no Dockerfile, either add one to that folder or upload/import it into managed Agent Lab so VulnoraIQ can generate one.
